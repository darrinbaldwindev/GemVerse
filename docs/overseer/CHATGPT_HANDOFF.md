# CHATGPT Overseer Handoff

## Operating chain
CHATGPT Head Overseer → GemVerse Project Overseer → authorised worker(s) → verification → project log → CHATGPT Head Overseer.

## Rules
- Fresh repository state before substantive work.
- Explicit task identity, scope, authority and acceptance criteria.
- Repository/test evidence determines completion.
- Gemini/Manus intelligence is input only unless correlated execution evidence exists.
- Fail closed on missing authority, credentials, capability or production gates.
- No production/destructive changes without project gates.

## Reporting contract
Every handoff reports STATUS, task/mission ID, decision-maker, executor, verifier, evidence, tests, changes, blocker and next authorised action.
