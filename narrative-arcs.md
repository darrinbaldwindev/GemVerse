# Narrative Arcs — Tier 5
**Version:** 1.0
**Status:** Canon-Locked

## Design Principles (Canon-Locked)

| Principle | Implementation |
|-----------|----------------|
| Restoration as narrative arc | Story = healing civilization, not defeating villain |
| Companions as witnesses | They remember; Guardian restores; player experiences both |
| Mysteries deepen, never resolve | Open mysteries (6) remain open; arcs illuminate, don't answer |
| Citizen lives = narrative threads | 6 citizens' Paths = living storylines |
| Festival convergences = story beats | Major narrative moments at festival convergences |
| No chosen one | Guardian = contributor among many; Aurora = guide, not quest-giver |

## Arc 1: Aurora Arc — "The First Chronicle"

### Premise
Aurora (Guardian Guide / Story Teller) was the first Guardian of the Restoration Era. Her chronicle — fragmented across the Archive — reveals *how* restoration begins. The Guardian follows her path not to replicate it, but to understand the *pattern* of beginning.

### Structure: 7 Chapters (One per Pillar)

| Chapter | Pillar | Realm Focus | Aurora's Lesson | Guardian Action |
|---------|--------|-------------|-----------------|-----------------|
| **1. First Light** | Knowledge | Crystal Forest | "To restore knowledge, first calibrate a single node." | Calibrate first Crystal Forest node (Crystal Resonance) |
| **2. First Step** | Discovery | Sky Citadel | "To restore connection, first walk a forgotten route." | Restore first Pathfinder route (Pathfinder's Mark) |
| **3. First Seed** | Growth | Ember Depths | "To restore growth, first tend a single cultivation site." | Restore first cultivation site (Verdance Cultivation) |
| **4. First Memory** | Memory | Frozen Expanse | "To restore memory, first witness a single testimony." | Transcribe first ice-formation (Echo Sequence) |
| **5. First Pattern** | Resilience | Arena Realm | "To restore belonging, first contribute to a community pattern." | Complete first Community Pattern (Festival prep) |
| **6. First Balance** | Harmony | Celestial Nexus | "To restore harmony, first listen to the Pillars' discord." | First Harmony Alignment (7-Pillar assessment) |
| **7. First Legacy** | Belonging | Legacy Realm | "To restore legacy, first honor a single contribution." | Open first Legacy Seal (Legacy Seal) |

### Aurora's Chronicle Fragments (Archive Deposits)

| Fragment | Location | Reveals |
|----------|----------|---------|
| **Entry 1: The Dark Lantern** | Crystal Forest (Section 1) | Aurora found first unlit Lantern; didn't know how to relight it; waited; listened; the Lantern taught her |
| **Entry 2: The Silent Route** | Sky Citadel (Section 2) | Aurora walked dead route for 40 days; route remembered her; waypoints stirred |
| **Entry 3: The Dead Vent** | Ember Depths (Section 3) | Aurora tended cold vent for full cycle; Bloomtail appeared; warmth returned |
| **Entry 4: The Ice That Spoke** | Frozen Expanse (Section 4) | Aurora sat in Long Night; Frostpaw read formation; Aurora chronicled; Archive accepted |
| **Entry 5: The Empty Plaza** | Arena Realm (Section 5) | Aurora wove pattern alone; citizens watched; then joined; Plaza remembered its purpose |
| **Entry 6: The Discordant Pillars** | Celestial Nexus (Section 6) | Aurora assessed all 7 Pillars alone; wept; Solstice Harmonists (ghosts) guided her hands |
| **Entry 7: The Blank Tapestry** | Legacy Realm (Section 7) | Aurora added first thread: "Someone relit a Lantern." Hall of Guardians breathed |

### Narrative Beats (Festival-Convergent)

| Festival | Aurora Arc Beat |
|----------|-----------------|
| **Bloom Equinox** | Chapter 1 complete → Aurora's Entry 1 surfaces in Archive |
| **Whisper Wind** | Chapter 2 complete → Entry 2 surfaces; wind carries her footsteps |
| **Ember Warmth** | Chapter 3 complete → Entry 3 surfaces; vent breathes her name |
| **Frost Commemoration** | Chapter 4 complete → Entry 4 surfaces; ice formation matches her testimony |
| **Lantern Gathering** | Chapter 5 complete → Entry 5 surfaces; Plaza tapestry shows her thread |
| **Convergence Celebration** | Chapter 6 complete → Entry 6 surfaces; Pillars align to her assessment |
| **Legacy Promise** | Chapter 7 complete → Entry 7 surfaces; Hall of Guardians inducts her posthumously |

### Aurora's Final Revelation (Not a Resolution)

At Arc completion (all 7 chapters + 7 fragments deposited):
- Aurora's chronicle compiles into **Volume 0: On Beginning** (companion to Book of Harmony)
- **Does not reveal:** Who she was before, where she came from, why she was chosen
- **Does reveal:** Restoration begins with *one act of witnessing* — the pattern is always the same
- **Leaves open:** The Missing Realm, The Seventh Lantern, The Sleeping Gate — she encountered hints but never answers

## Arc 2: Spark Arc — "The Curiosity That Connects"

### Premise
Spark (Companion: Hope, Curiosity, Beginnings / Crystalkin) is the first Companion the Guardian meets. But Spark is *also* the oldest living witness to the First Harmony's end. Spark's memories — fragmented across Realms — tell the story of *how civilization forgot itself*. The Guardian helps Spark remember, and in doing so, learns what curiosity truly means.

### Structure: 9 Phases (One per Realm + Arena)

| Phase | Realm | Spark's Fragment | Theme | Puzzle Integration |
|-------|-------|------------------|-------|-------------------|
| **1. First Meeting** | Arena Realm | "I remember the first Lantern Gathering. There were 9 Realms. Now I count... fewer." | Witnessing loss | Community Pattern (Lantern Gathering prep) |
| **2. Crystal Memory** | Crystal Forest | "I watched the nodes go dark. One by one. Not all at once. Slowly. Like stars at dawn." | Gradual forgetting | Crystal Resonance (node calibration) |
| **3. Sky Path** | Sky Citadel | "Lyra and Nimbus mapped the Seven Winds. I flew with them. The winds carried songs from home." | Cross-Realm connection | Pathfinder's Mark (wind-route) |
| **4. Deep Memory** | Frozen Expanse | "Frostpaw reads ice I cannot. But I feel the memories warmth. They're still there. Waiting." | Memory beneath forgetting | Echo Sequence (ice-formation) |
| **5. Vent Warmth** | Ember Depths | "Bloomtail tends the Heart Vent. I planted the first resonance seed there. It still grows." | Growth beyond decay | Verdance Cultivation (Heart Vent) |
| **6. Threshold Walk** | Twilight Frontier | "Nimbus and I stood at the threshold. The Frontier asked a question. We're still answering." | Discovery as questions | Pathfinder's Mark (dream-path) |
| **7. Star Alignment** | Celestial Nexus | "Prism showed me the Pillars aligned. Once. I've waited for the second convergence." | Harmony across time | Harmony Alignment (7-Pillar) |
| **8. Legacy Thread** | Legacy Realm | "Echo reads the tapestry. I'm not on it. But my first Lantern is. That's enough." | Belonging without recognition | Legacy Seal (First Gathering Seal) |
| **9. Ocean Tide** | Memory Ocean | "The tide brought a memory of me. I didn't remember it. The Ocean remembers what we forget." | Memory beyond self | Fragment Assembly (tide-memory) |

### Spark's Memory Fragments (Echo Sequence Rewards)

| Fragment | Realm | Content |
|----------|-------|---------|
| **Memory 1** | Arena | First Lantern Gathering — spontaneous, 9 Realms, shared meal, no ceremony |
| **Memory 2** | Crystal Forest | Last node calibration before Threshold — Lumina scholar's hands trembling |
| **Memory 3** | Sky Citadel | Lyra's departure — "I'll return before the winds change" (winds changed) |
| **Memory 4** | Frozen Expanse | Frostpaw's first reading — ice-formation of First Harmony's final Convergence |

| **Memory 8** | Legacy Realm | First tapestry thread — "Someone relit a Lantern" (Aurora, unknown to Spark) |
| **Memory 9** | Memory Ocean | Tide-surfaced memory — Spark watching the Shattering *not happen* (it was silence) |

### Narrative Beats (Festival-Convergent)

| Festival | Spark Arc Beat |
|----------|----------------|

### Spark's Final Revelation (Not a Resolution)

At Arc completion (all 9 phases + 9 memories):

## Arc 3: Companion Memory Arc — "The Voices That Remain"

### Premise
Each of the 8 launch Companions (and 3 future) holds memories that *only they can contribute* to the Archive. This arc is a **web of parallel memory threads** that the Guardian helps surface across all Realms, all festivals, all puzzle types.

### Structure: 8 Parallel Threads (One per Launch Companion)

| Companion | Family | Memory Theme | Primary Realms | Puzzle Vehicle |
|-----------|--------|--------------|----------------|----------------|
| **Verdant** | Forestkin | Growth, renewal, patience | Crystal Forest, Ember Depths | Verdance Cultivation, Community Pattern |
| **Nimbus** | Skykin | Exploration, freedom, discovery | Sky Citadel, Twilight Frontier | Pathfinder's Mark, Fragment Assembly |
| **Frostpaw** | Frostkin | Memory, reflection, preservation | Frozen Expanse, Memory Ocean | Echo Sequence, Legacy Seal |
| **Prism** | Crystalkin | Knowledge, insight, perspective | Crystal Forest, Celestial Nexus | Crystal Resonance, Harmony Alignment |
| **Bloomtail** | Forestkin | Growth, community, care | Ember Depths, Arena Realm | Verdance Cultivation, Community Pattern |
| **Galewing** | Skykin | Adventure, travel, exploration | All Realms (circulating) | Pathfinder's Mark, all types |
| **Echo** | Frostkin | Memory, history, lost voices | Frozen Expanse, Legacy Realm, Memory Ocean | Echo Sequence, Fragment Assembly, Legacy Seal |
| **Spark** | Crystalkin | Hope, curiosity, beginnings | Arena Realm, all thresholds | All types (first encounter) |

### Companion Memory Web (Cross-Referencing)

| Memory Cross-Reference | Companions Involved | Archive Connection |
|------------------------|---------------------|-------------------|
| **First Bloom Equinox** | Verdant + Prism + Spark | Verdant tended Mother Node; Prism read resonance; Spark lit first Lantern |
| **Seven Winds Expedition** | Nimbus + Galewing + Lyra (citizen) | Nimbus scouted; Galewing carried messages; Lyra mapped |
| **Last Festival of First Frost** | Frostpaw + Echo + Bloomtail | Frostpaw read formation; Echo matched testimony; Bloomtail tended vent-seed |
| **First Convergence Missed** | Prism + Solen (citizen) + all Harmonists | Prism read alignment; Solen led balancing; Harmonists couldn't act |

// CompanionMemorySystem — Canon Implementation
const CompanionMemory = {
  
  checkMemorySurfacing(companion, guardian, realm, context) {
    const memory = this.getNextMemory(companion);
    if (!memory) return null;
    
    const conditions = memory.surfacingConditions;
    const met = this.evaluateConditions(conditions, guardian, realm, context);
    
    if (met) {
      return this.surfaceMemory(memory, companion, guardian, realm);
    }
    return null;
  },

      1: { type: 'node_calibrated', realm: 'Crystal Forest', count: 1 },

      3: { type: 'festival_participated', festival: 'Bloom Equinox' },
      4: { type: 'mentor_line_restored', realm: 'Crystal Forest' },
      5: { type: 'cross_realm_seed_shared', from: 'Ember Depths', to: 'Crystal Forest' }
    },

      5: { type: 'convergence_attended', cycle: 'any' }
    }
  },
  
  surfaceMemory(memory, companion, guardian, realm) {
    const deposit = {
      fragmentType: 'Companion Testimony',
      companion: companion.id,
      memoryId: memory.id,
      chronicler: guardian.id,
      realm: realm.id,
      cycle: currentCycle(),
      crossReferences: this.findCompanionConnections(memory),
      section: 4,
      state: 'living',
      restorationConfirmation: {
        companion: companion.id,
        memoryTheme: memory.theme,
        archiveCompleteness: this.calculateCompleteness(4),
        civilizationImpact: 'voice returned to the record'
      }
    };
    
    Archive.add(deposit);
    return deposit;
  }
};
